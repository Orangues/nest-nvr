Privacy policy

Last updated: 25 November 2026

nest-nvr is a private application used only by its owner, to access the owner's own Google Nest devices.

Data accessed

With the owner's authorization, the application uses the Google Smart Device Management API to read device information and camera streams from the owner's own Nest devices.

How data is used and stored

Data is used only to display and record the owner's camera feed. Recordings and access tokens are stored solely on the owner's private home server.

Sharing

No data is sold, shared with or disclosed to any third party. No analytics or advertising is used.

Revoking access

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions).

Contact

Questions can be raised through the GitHub profile that hosts this page.
